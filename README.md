# 文生图提示词工程系统 (Prompt Creator)

一个用于创建和管理文生图提示词的本地网页应用程序（SPA）。

## 功能特性

### 1. 词条清单
配置不同内容维度的提示词，支持：
- **文本框类型**：用于自由输入的提示词
- **复选框类型**：预定义可选项的提示词
- 自定义优先级（1-1000，数值越小优先级越高）
- 分组管理
- 显示/隐藏控制

### 2. 文本模板
创建提示词模板：
- 定义生成规则（使用 `{词条名称}` 作为占位符）
- 设置额外固定要求（追加到生成结果末尾）

### 3. 提示词工程
创建项目并生成提示词：
- 选择一个模板作为基础
- 配置启用的词条及其优先级
- 为复选框类型词条选择启用的选项
- 实时计算可能的组合数
- 支持随机种子控制生成结果

## 使用方法

1. 直接用浏览器打开 `index.html` 文件
2. 或启动本地服务器：
   ```bash
   python3 -m http.server 8080
   ```
   然后访问 `http://localhost:8080`

## 数据存储

- 所有数据存储在浏览器的 LocalStorage 中
- 支持数据导出/导入功能（JSON格式）
- 默认配置示例保存在 `data/` 目录下

## 文件结构

```
promptCreator/
├── index.html          # 主页面
├── css/
│   └── style.css       # 样式文件
├── js/
│   └── app.js          # 应用逻辑
├── data/
│   ├── itemConfig.json      # 词条配置示例
│   └── templateConfig.json  # 模板配置示例
└── runData/            # 项目运行数据目录
```
